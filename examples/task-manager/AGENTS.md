# Codex Automata Task Manager Example: Agent Instructions

This directory contains a worked example of the Codex Automata methodology applied to a simple task manager.

The example demonstrates the full flow: specification, architecture, interface contracts, test plan, agent tasks, and human review.

**Do not modify these files as part of normal project work.** They serve as a reference artifact.

To create your own project, run `scripts/init.ps1` (or `init.sh`) from the Codex Automata repo, or copy the contents of `harness/` into your project root.
