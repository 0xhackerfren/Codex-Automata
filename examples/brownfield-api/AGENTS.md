# Codex Automata Brownfield API Example: Agent Instructions

This directory contains a worked example of brownfield adoption: retrofitting specifications, SDK types, and tests onto a legacy bookmarks REST API.

The example demonstrates audit, recovery-based onboarding, and gap assessment—not greenfield intake through casting.

**Do not modify these files as part of normal project work.** They serve as reference artifacts.

To adopt the methodology on your own existing codebase, run `scripts/init.ps1` (or `init.sh`) from the Codex Automata repo into your project root, then follow `reference/brownfield-onboarding.md`.
